These guides take you from install to a wall you trust. Read them in order, or jump to the one you need.

## Start here

1. [Install claude-garage](/docs/guides/install/): npx, the shell installer or PowerShell, plus tmux and the background daemon.
2. [Your first wall](/docs/guides/first-wall/): add a project, start sessions, and move around the wall.
3. [Run many sessions at once](/docs/guides/many-sessions/): groups, the amber needs-input signal, and the jump and queue keys.

## Work safely

- [Sessions in git worktrees](/docs/guides/worktrees/): give each session its own folder and branch, then merge, discard or keep it.
- [Nothing gets lost](/docs/guides/nothing-lost/): how tmux keeps sessions alive, restoring after a reboot, and recovering drafts.
- [Coming from terminal tabs](/docs/guides/from-terminal-tabs/): what changes and what stays the same when you switch over.

## Plugins and settings

- [Use and install plugins](/docs/guides/plugins/): the nine built-in plugins, installing more from GitHub, and turning them on or off.
- [Build your first plugin](/docs/guides/first-plugin/): scaffold, write, test and publish a plugin in about 20 minutes.
- [Configuration](/docs/guides/configuration/): environment variables and the `config.toml` file.

## Contribute

- [Contributing](/docs/guides/contributing/): build from source, run the tests and find your way around the code.

Want to try the keys before you install? Use the [interactive tutorial](/try/).
